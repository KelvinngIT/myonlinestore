# CashBack Store – Online Shopping Demo

A clean, modern **e-commerce store** demo where users can browse products, add items to cart, and **settle payment online**.

Inspired by cashback / online mall experiences (like HKTVmall CASHBACK). Built with pure HTML, CSS & Vanilla JavaScript — no frameworks required.

---

## Features

- Product catalog with cashback badges
- Shopping cart (persisted in LocalStorage)
- Quantity controls & remove items
- Full checkout form (contact + shipping + payment)
- Online payment simulation (test card flow)
- Order success confirmation with Order ID
- Fully responsive (mobile-friendly)
- Ready to push to GitHub

---

2. Open `index.html` in any modern browser
